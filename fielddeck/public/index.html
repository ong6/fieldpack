    Start local. Stay local.
    Run npm start --prefix /home/jun.ong/Sideproject/fielddeck or node /home/jun.ong/Sideproject/fielddeck/server.js, then open http://127.0.0.1:4311. Requires Node 22 or newer. No install step or runtime dependencies. Use node server.js --help for options and npm test for checks from the app directory.
    Your library autosaves to the versioned data/workspace.json with atomic writes. Existing deck.json needs explicit migration; a byte-for-byte deck.pre-migration.json is preserved first, and the original is not changed. Invalid files fail closed. “Saved locally” means the server confirmed it. Keep the server running while editing. Each save targets a deck ID and revision, never another window’s selected deck. Failed saves or switches keep edits here; export JSON before reloading a conflict. Any local user with access to this machine may access the studio.
    
    
    A library, with recovery points
    New deck / guided starter creates an independent deck; it never replaces earlier work. Choose discovery, architecture or pilot-readout to load the existing skill’s template and capture audience, requested decision, constraints and evidence gaps. Agent brief saves this context beside the deck; download brief JSON or a ZIP of the brief, v1 deck JSON and complete selected skill directory. No agent calls, uploads or automatic installations happen. The deck JSON inside that ZIP includes notes.
    Manage library opens, duplicates or reversibly archives decks. Rename in Deck settings. Limits: 24 decks including archives, 12 named checkpoints per deck, 32 MiB total workspace, and 30 slides / 1 MiB per v1 deck. Nothing is silently discarded to meet a limit. Export backups and start a separate server storage directory if full. Checkpoints preview every slide, brief and notes before a confirmed restore. Archive is read only; unarchive to edit.
    Undo / Redo covers text, rows, slides, reorder, settings, briefs, imports and checkpoint restores in this window. Consecutive typing in the same field is grouped after a short pause. Up to 80 steps / 8 MiB of history are kept in memory, not across reloads or deck switches; use named checkpoints for durable milestones. Ctrl / Cmd + Z and Shift + Z (or Ctrl + Y) work outside text controls. Inside an input or textarea, native text undo is left alone; use the toolbar to undo a whole edit. Undo also autosaves to the same deck.
    
    
    Build the argument
    Choose a slide from the storyline, edit it on the right, and add a chapter with +. Reorder using the up and down buttons. Changing layout retains other layout content in JSON; only the active layout is shown. Delete and import ask for confirmation. A blank deck starts with one title slide.
    Evidence means sourced observation, not certainty. Assumption means unvalidated inference. Proposal means a recommendation or target. Sources are plain text, not fetched URLs. The clarity check combines deck-wide editorial checks for missing provenance, dense copy, and absent next steps with a measured fit check for the currently selected preview. A measured warning reports the preview size when text crosses its footer or canvas boundary; it only measures the selected preview. Use Review all slides for every slide at 1600 × 900 plus editorial checks. Its JSON report includes the content hash, saved revision, renderer hash, timestamp, viewport and limits. Edits, theme changes, switching decks, and detected renderer changes mark it stale. Preflight is not factual verification or a guarantee of print correctness. Content is never removed to make it fit. Split crowded slides, use concise source keys with full citations in notes, and inspect every exported slide.
    
    
    Present and hand off
    Present: use ← / →, Page Up / Down, Home / End, or the navigation buttons. Escape closes presentation; N toggles notes; F requests fullscreen. Export JSON: editable backup including notes and retained layout content. Import: validated version 1 JSON, up to 1 MiB / 30 slides; replaces the working deck after confirmation. Export your current deck first.
    Export HTML: a self-contained, offline presentation without notes or network requests. Its toolbar supports overview and navigation. Print / PDF: opens the saved presentation; choose Print / PDF, landscape, background graphics on, and browser headers/footers off. Save as PDF using your browser. Browser paper sizes can differ from 16:9; HTML is the exact-ratio handoff. There is no PowerPoint export or automatic PDF engine.
    Keyboard: Tab moves through controls; Enter / Space activates buttons; Ctrl / Cmd + S saves; Ctrl / Cmd + Enter presents outside text fields. No automatic cloud AI calls are made.
